# Mavra.Net

Türkiye'nin sohbet ve chat platformu.

Mavra.Net; sohbet odaları, mobil sohbet ve web tabanlı chat hizmetleriyle insanların yeni insanlarla tanışmasını, sohbet etmesini ve arkadaşlık kurmasını sağlayan bir platformdur.

## 💬 Hizmetler

- Sohbet odaları
- Mobil sohbet
- Web tabanlı chat
- IRC sohbet
- Farklı konularda sohbet kanalları
- Yeni insanlarla tanışma ve arkadaşlık
